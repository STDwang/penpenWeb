# 线上验收 · 2026-10-21

地址：[https://penpen-web.vercel.app/](https://penpen-web.vercel.app/)。由用户完成 Vercel 导入后提供，本轮验证并同步文档，未重新创建或变更部署。

## 用户路径

访客进入首页，识别工程师定位，播放/暂停或拖动轨迹示意，进入案例/个人项目详情，阅读关于与简历，并下载 PDF。页面内容来自构建时本地项目数据，浏览时不依赖远程 GitHub/CSDN 接口。

## 实际验证结果

测试工具：仓库内 Playwright 用例，Microsoft Edge。实际目标为公开 Vercel 地址；1440×1000 桌面、768×1024 平板、390×844 手机，9 个浏览器用例全部通过。

| 边界 | 结果与证据 |
| --- | --- |
| 首页与图片 | 中文定位显示；项目图片完成加载；无首页客户端异常；保存各尺寸真实全页截图 |
| 轨迹控制 | 初始 12 秒；方向键推进到 12.1 秒；播放时进度增长，暂停可恢复 |
| 车辆选择 | 键盘选择 028 车辆，aria-pressed 与状态文本同步 |
| 减少动态效果 | 媒体设置变化后保持暂停并显示说明 |
| 手机导航 | 打开导航，Escape 关闭并恢复按钮焦点 |
| 页面跳转 | 实际点击进入工程列表和轨道案例；其余案例、实验室、关于、简历全部返回 200 |
| 响应式 | 被检查页面在各尺寸无文档级横向溢出 |
| PDF 下载 | 返回 200，文件头为 `%PDF-`；未把文件头检查表述为全量内容比对 |
| SEO 审阅状态 | 页面描述存在；robots meta 含 noindex，robots.txt 为 Disallow: / |
| 错误路径 | 未知案例与未知路由返回 404，页面提供返回入口 |
| 无 JavaScript | 首屏正文与静态道路图可见，案例入口仍可跳转 |

执行批次：桌面交互 1 项、桌面其余检查 2 项、平板/手机 6 项，共 9 项；未重复执行已经通过的同一检查。

## 管理接口的验证范围

当前 Vercel 连接的已授权团队仍未列出此项目，按 `penpen-web` 和在线域名查询均返回 404；GitHub 部署列表也未提供可用于确认的记录。因此未确认 Vercel 项目所属账户/团队、Production/Preview 环境类型、部署 ID 或精确提交 SHA。公开站点的功能验证不能代替这些后台信息，也不会因为后台查询失败就否定已经通过的公开页面验证。

本机 Windows curl 曾因证书吊销服务不可达而失败；未禁用 TLS 校验。通过使用本机已有代理的真实浏览器完成检查，测试没有启用 ignoreHTTPSErrors。
