## 处理与贡献边界

- 商业截图裁去标题栏本地路径、底部状态栏或桌面浮层；轨道画面减少下方空白。保留复杂拾取候选菜单、排放图表、济达交通水印，不改写或生成运行内容。
- ImagePlayer 遮盖顶部路径、提示中的文件名；牙片另遮盖影像附带文字。玩偶图原有水印保留。
- 牙片按用户最新要求公开，用户说明为网上示例；不把它当作用户自身医疗资料，也不声称医疗诊断能力或替素材授予许可证。
- 输出统一为 1600×900 WebP，以留边完整展示而不是拉伸。详情可打开完整脱敏图片；手机卡片不裁掉候选菜单和双视图。
- `design/prepare-module-screenshots.mjs` 记录裁切、显式遮盖与压缩步骤。原始附件仅在忽略的 `work/source-screenshots/`，不提交公共仓库。
- 排放新增内容仅描述用户确认负责的模块及截图可见的可视化能力，不推断排放模型归属、精度、减排效果或性能数字。
- 本轮没有读取、复制或发布济达内部源代码、提交记录及客户数据；截图已足以完成本次替换。

## ImagePlayer README

本地 ImagePlayer 项目 README 已更新，新增三张相同的脱敏截图、技术结构、CMake 构建说明、使用方式与能力边界；旧 README 在本站忽略的工作目录中保留备份。

依据该项目本地源码核对：动态多视图、拖放缩放、鸟瞰图、像素显示、QImage/RAW 取反、RAW 自动亮度、直方图与保存路径。去噪只有 QML 入口而无对应后端方法，不列为已完成。普通图片像素查询取红色通道，不泛称精确灰度测量。保留原有未提交的 C++ 修改，不纳入本次文档更新。

去除无关 ImageJ CI 徽章和笼统 Public Domain 声明；内置 QCustomPlot 文件有 GPL v3 或更新版本声明，README 提示分别核查依赖和素材许可。本轮不变更任何许可证，不重新编译或验收原生应用完整功能。
