# UI 修订与审阅 · 2026-10-21

## 用户反馈与范围

用户要求参考 `https://lovelyyoshino.github.io/index.html` 的 UI / 交互，解决“重点不突出、图片有效信息不足”，查找济达官网公开软件画面，并以横向滑动卡片展示项目、Demo 与作品集。

本轮沿用 Next.js / React / TypeScript、现有职业定位、四年经验和路由，不新增网站后台、不修改任职日期、不把目标方向描述为已有机器人经验、不修改简历源文件，也不迁移到 WorkBuddy。以可操作本地版本作为下一审阅节点，未提交/推送或覆盖现有线上站点。

## 交付

- 首屏：身份与岗位成为主标题；紧接已有经验、三个模块和目标方向。真实产品画面替代主导首屏的泛化示意；“查看工程案例 / 下载简历”保持主行动。
- 经验入口：四年、轨道模块 25 项测试、微中观协同分别链接到对应依据。25 项沿用个人简历，不推导全部产品的质量或性能。
- 工程与作品：首页及两个列表页采用同一原生横向画廊。桌面露出两张及下一张边缘，手机露出下一张卡。支持触屏、触控板、左右按钮、左右键、Home/End；滚动首尾正确禁用按钮，不自动轮播，不劫持纵向滚轮。
- 卡片：始终显示主图、类别、重点、摘要、个人职责/实现、交付链路、技术标签；详情、源码、外部 Demo / 项目介绍分开提供。
- 图像：济达官网二维路网、三维窗口与结果热力图仅作产品背景。图片旁显示来源与“不对应个人模块截图”的范围，详情继续保留原创架构图。原有 GPUView、Dreamscape 实机保留；补充 MISTLOOP 实际在线启动画面，ImagePlayer 仍为有标注的功能示意。
- 交互示意：原轨迹播放器移到作品之后，仍支持播放、暂停、选择、进度与减少动态效果；不冒充商业仿真结果。
- 参考站取舍：借鉴终端式简介、图卡与标签反馈；未复制其个人数据、头像、项目、代码；不引入开机等待、技能百分比、隐藏正文的入场动画或远程粒子依赖。

素材原始地址、处理方式和权属边界见 `design/references.md`。所有浏览所需图片本地化，不在访客加载时请求济达官网、GitHub 图片或远程字体。

## 验证

验收故事：招聘访客从首页读懂岗位和现有能力 → 横向浏览商业/个人案例 → 查看具体职责与图片来源 → 进入详情 / 源码 / 演示或下载简历。

- 类型检查通过，生产构建通过；所有内容路由继续预渲染。
- Playwright + Microsoft Edge，1440×1000、768×1024、390×844，共 12 项浏览器检查通过（最终图像和内容更新后已复验）。
- 覆盖：横滑按钮、首尾禁用、左右键和 Home/End、真实 CDP touch 滑动、图片来源、工程详情、所有详情 200、整页无横向溢出、PDF 签名、404、描述、noindex/robots、移动菜单和 Escape、无 JavaScript 时横向列表详情导航、原轨迹交互与减少动态效果。
- 本轮没有新增 API、数据库或环境变量。内容从本地结构生成；样式、图像和下载由同站点提供，无新增运行时外部边界。
- `previews/refresh-*.png` 为本地实际页面截图，`online-*.png` 为此前线上版本；不混称已部署。
- MISTLOOP 本轮经代理验证公开页面与“进入林子”后的初始运行画面，并获取截图；未验收声音、通关、完整玩法或无代理访问。Dreamscape 外链是项目介绍而非可玩游戏。

## 本轮审阅入口

- 本地服务：`http://127.0.0.1:3001/`，启动命令 `cd code; npm run dev -- --port 3001`。
- `previews/refresh-desktop-hero.png` / `refresh-mobile-hero.png`：首屏。
- `previews/refresh-desktop.png` / `refresh-tablet.png` / `refresh-mobile.png`：实际全页。

请优先审阅：是否能迅速读懂岗位与贡献；商业案例与个人实验的比例；横向卡片的信息量和操作感。取得反馈后再继续细化与线上同步。
