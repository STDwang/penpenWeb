# 阶段 A + B · 高级白主题与全幅分镜舞台 · 2026-10-26

面向「人物即全站背景 + 高级白 + 高级磨砂玻璃」的整站改版。

- **阶段 A**：配色、字体、磨砂玻璃材质体系（不依赖新素材）。
- **阶段 B**：角色成为全站背景、相机机位、两侧信息与按钮、装置表面读数与内容停靠。

## 关键发现

检查最新代码时发现 `code/src/app/scene.css` 已经把「单幅全出血场景 + 装置聚焦机位」的样式写好了，但 `home-stage.tsx` 里缺少对应的标记——`.scene-intro-side` 侧栏在样式里被完整定义，组件里却没有这个元素。因此本轮的阶段 B 主要工作是**补齐标记并校准对位**，而不是重写场景系统。

同时确认仓库里已有 `white-studio-*` / `dark-studio-*` 十张分镜帧，角色已佩戴科技眼镜、带屏手表与可投影头戴。**这批帧比新生成的 AI 角色图更贴合高级白主题**（白色服装与白棚融为一体，即参考站 OYLA 的处理方式），因此最终采用现有分镜帧，新生成的图仅作对照。

## 阶段 A · 主题与材质

### 配色迁移

`code/src/app/globals.css` 与 `code/src/app/future.css` 里 140 余处硬编码深色，按语义一次性映射到纸白体系（一次性脚本 `work/migrate-paper-theme.mjs`，结果已落盘，脚本在忽略目录内）。

| token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#f4f2ef` | 纸面底色 |
| `--surface` | `#fbfaf8` | 面板底 |
| `--raised` | `#ffffff` | 抬起层 |
| `--text` | `#17140f` | 主文字（墨） |
| `--muted` | `#4c463f` | 次级文字 |
| `--subtle` | `#797066` | 三级文字 |
| `--line` | `#17140f1f` | 发丝线 |
| `--accent` | `#0d6a61` | 深青，唯一强调色 |
| `--amber` | `#8a5a1c` | 暖金，极少量标记 |

强调色从亮青 `#71e2d4` 改成深青 `#0d6a61`：亮青在白底上对比度不足，深青在白底和截图上都能读，且与角色服装上的青色描边同源。

### 玻璃体系

新增 `code/src/app/theme-paper.css`（在 `globals.css`、`future.css`、`scene.css` 之前引入，作为主题层），定义 `--glass-1/2/3`、`--glass-line`、`--glass-inset`、`--glass-shadow`、`--glass-blur`。面板从「深底 + 青紫渐变 + 内发光」改成「白底 + 极淡暖调渐变 + 顶部高光 + 暖调投影」。纸纹噪点从 12% 降到 4.5%，在白底上像纸纹而不是灰渍。

### 字体

`next/font/google` 自托管，构建期下载、运行期本地加载：

- `Bodoni_Moda`（400/500）→ `--font-display`，拉丁展示体
- `Noto_Serif_SC`（300）→ `--font-display-cn`，中文轻宋
- `Inter`（400/500/600）→ `--font-sans`，界面与正文

标题 `h1`/`h2` 使用 `Bodoni Moda → Noto Serif SC` 栈（拉丁命中前者、中文命中后者）。中文轻宋按 unicode-range 切片，浏览器只取用到的分片。

构建产物：112 个 woff2、3.3MB（`out/` 已在忽略目录内）；主样式表 103KB，其中 133 条 `@font-face`。

## 阶段 B · 场景与交互

### 补齐的标记

`code/src/components/home-stage.tsx`：

- **左侧**：身份、衬线大标题、简介、`探索工作成果` / `下载简历` 按钮、关键数字。
- **右侧 `.scene-intro-side`**：`CAMERA STATIONS` 引导卡，含一句衬线说明与四个机位按钮（全景 / 眼镜视野 / 腕表界面 / 耳机投影），点击即驱动镜头。
- **常驻 `.scene-camera-strip`**：右上角紧凑机位条，在每个机位都可继续切换镜头，不必退回全景。
- **`.device-chip`**：贴在装置上的精简读数（编号 + 标题 + 一行摘要 + 关键数字），用一条引线与装置圆点相连。

### 相机与对位

镜头运镜沿用既有 `data-pose` 驱动的 `transform` 变换（`scene.css`），本轮只做两处调整：

1. 腕表机位把停靠卡片改到左半区，右侧留给手表与读数。
2. 装置读数按实测渲染坐标逐机位校准：

| 机位 | 装置 | 读数锚点 |
| --- | --- | --- |
| 工作成果 | 眼镜 | 51% / 18.4% |
| 个人项目 | 手表 | 特写帧 61.4% / 39.8%，全景帧指向伸出的手腕 75.2% / 63.2% |
| 关于与联系 | 头戴耳机 | 20.8% / 22.2% |

腕表特写帧只持续 850ms 随即切回全景，所以两个状态各有一套锚点。

### 内容停靠

采用混合形态：装置表面只放精简读数，完整内容以磨砂玻璃卡片停靠在旁边（工作成果 / 个人项目是带真实截图的卡片轮播，关于与联系是一张完整信息卡）。
