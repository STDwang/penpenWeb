# 深色仿真工作台 · 视觉与交互规范 v1

## 风格与构图

石墨黑画布、冷白中文、青蓝轨迹，少量琥珀标记检查点。以专业工程工具的空间感组织作品，不放虚构监控数据或装饰性 KPI。首屏图与案例图是原创矢量示意；项目图使用实际截图。

桌面视觉稿 1440×3870px，左右边距 88px，主体宽 1264px。导航高 80px；首屏左文案右示意，案例区一个横向主案例、两个并排辅助案例，实验室两张主图卡与两个文字入口。

手机视觉稿 390×5090px，左右边距 24px，主体宽 342px；主文案、按钮、场景、时间轴依次堆叠。案例与能力列表改单列，联系方式顺序展示；手机减少轨迹数量。

本机视觉稿用 Microsoft YaHei、Consolas；字体不随仓库分发。正式网站用系统中文无衬线字体栈与系统等宽字体，避免远程字体阻塞。桌面主标题 54px，手机 35px；段落 14–16px，技术图注 10–12px。小图内标签不承担唯一的信息表达，正式交互补充可读状态说明。

面板圆角 4–6px、细边、少量填色，不使用大范围辉光。普通跳转以箭头提示；主 CTA 实色青绿，次 CTA 细边。图标采用原创线条。

## 阶段二交互契约

- 导航跟随正常滚动，无强制滚动、入场等待或自定义鼠标。手机菜单提供展开状态、关闭和焦点恢复。
- 道路图使用固定数据，初始暂停于 12/30 秒。播放/暂停按钮有文本或无障碍名称；进度使用原生范围输入，支持左右键调整。
- 车辆作为可聚焦按钮，点击或 Enter/Space 选中，状态文字说明所选轨迹；切换选择保持时间进度。图中数据明确是演示数据。
- 减少动态效果时默认暂停、取消自动入场运动；页面不在背景标签继续推进演示。静态 SVG 是客户端脚本未加载时的降级画面。
- hover/focus 只调整边框、文字、箭头位置；不改变关键内容可见性。按钮和链接有可见焦点，移动端实际点击区至少 44px。
- 自适应断点：768px 以下单列；768–1199px 缩窄双栏并精简图注；1200px 以上使用桌面构图。长邮箱可以换行，标题不裁切，截图保留主要内容。
- 静态设计稿中的播放图标、进度和标签是视觉状态，不宣称可交互。SVG 和 PNG 是同一渲染源的导出。

## 第一轮审阅重点

首屏是否像你希望呈现的工程师；专业案例与个人作品的比例；图案的复杂度；中文标题、留白和整体暗色舒适度。阶段二前只调整这些高影响设计选择，不扩展后台、CMS 或重型三维场景。
